# 06 客戶夥伴

## 目標
把客戶和合作夥伴都記下來，不漏掉任何一個該追蹤的人。

## 客戶要記錄的欄位
姓名／暱稱、來源（IG、Threads、LINE、介紹、講座）、國曆生日、數字基因密碼、
今年流年、諮詢日期、諮詢重點、買過的服務、下次追蹤日、備註

## 夥伴要記錄的欄位
夥伴名稱、合作方式（介紹客戶、合辦講座、異業合作）、聯絡方式、
介紹了哪些客戶、分潤比例、已付／未付、備註

## 工具
- 建議做成一個只有惠姐看得到的「客戶管理網頁」（私人，可新增、搜尋、篩選）
- 管理表網址記在這個資料夾的 `管理表網址.md`

## 隱私規則（很重要）
- 客戶個資不可存進 GitHub 儲存庫（儲存庫可能是公開的）
- 不可把客戶資料傳給任何外部服務做行銷
- 這個資料夾只放「欄位設計、使用說明、範本」，不放真實客戶資料

## 會用到的範本
- `追蹤訊息範本.md`：諮詢後 3 天、1 個月、流年轉換時的關心訊息
- `介紹獎勵.md`：夥伴或舊客戶介紹新客的獎勵辦法（內容要問惠姐）
